# BAドリル

スターバックス ブラックエプロンチャレンジ対策の、自分専用の問題演習アプリです。
PWA（ホーム画面に追加して使うWebアプリ）で、HTML / CSS / 素の JavaScript だけで動きます。
成績・問題データはすべて端末の中（IndexedDB）に保存され、サーバーには送られません。

## できること

- **単元で解く**：テキストの空欄埋め（4択 or めくって自己採点）、単元の全問題、テキスト順 / ランダム
- **ランダム・模試**：範囲・問題数・形式（択一 / 複数選択 / ○× / 並べ替え / 穴埋め→4択変換）を選んで出題。苦手優先、タイマー
- **本番モード**：4択40問＋複数選択10問（100点満点・制限30分）。解説は最後にまとめて表示
- **苦手復習**：間違えた問題だけを解く。苦手の問題を2回連続で正解すると「克服」
- **成績**：単元別の正答率、本番の点数の推移、直近14日の学習時間
- **バックアップ**：成績・パック・設定を1つのJSONに書き出し／読み込み。Claudeに渡す用の成績書き出しもあり

## ファイル構成

```
index.html      画面の土台（1ページ）
style.css       見た目（ライト／ダーク、文字サイズ）
app.js          画面の切り替え、イベント、出題の進行
db.js           IndexedDB の読み書き
pack.js         問題パックの検証・取り込み・単元の合体
quiz.js         出題、選択肢の生成、模試の抽選、採点
stats.js        成績・苦手・学習時間の集計
sw.js           Service Worker（オフライン用キャッシュと更新の検知）
manifest.json   PWAの設定
icons/          アイコン（192px・512px）
sample-pack.json 架空の内容のサンプル問題パック（動作確認用）
```

## インストール（Android / Chrome）

1. GitHub Pages で公開する（リポジトリの Settings → Pages → Deploy from a branch → `main` / `/ (root)`）。
2. 公開されたURLを Chrome で開く。
3. Chrome のメニュー（⋮）→「ホーム画面に追加」。
4. ホーム画面の「BAドリル」から開く。以後はオフラインでも動きます。

## 問題パックの取り込み

1. 設定 →「パックを取り込む」の欄に、JSONを貼り付ける（「貼り付け」ボタン、または入力欄を長押しして貼り付け）。
   ファイルを選ぶ（複数可）でも取り込めます。
2. 「検証して取り込む」を押すと、パック名・バージョン・単元数・問題数・エラーが表示されます。
3. エラーがあれば、問題ごとに「どの問題のどのフィールドが何か」が出ます。「エラーの問題を飛ばして取り込む」か「中止」を選べます。
4. 取り込み後、入力欄は空になります。

- 同じ `packId` で `packVersion` が大きいものは、古いパックを丸ごと置き換えます。
- 同じか古い `packVersion` は、確認のあとに置き換えます。
- 置き換えても成績（progress）は問題の `id` で残ります。
- 複数のパックを入れられます。単元は `unitId` が同じなら合体して表示されます。
- 設定の一覧から、パックを1つずつ削除できます（成績は消えません）。

## パック形式（要約）

詳しい仕様はアプリの作成メモを参照してください。ここでは最低限の形だけ示します。

```json
{
  "schema": 1,
  "packId": "sample-pack",
  "packVersion": 1,
  "title": "サンプルパック（架空の内容）",
  "updatedAt": "2026-11-18",
  "groups": [ { "id": "sg1", "title": "架空の大単元 A", "order": 10 } ],
  "units":  [ { "id": "sa-1", "groupId": "sg1", "title": "架空の単元 A-1", "order": 1, "source": "text", "pages": "p.1-2" } ],
  "questions": [
    { "id": "sa-1-001", "unitId": "sa-1", "type": "cloze", "order": 1,
      "text": "架空のカフェは、{{1}}年に始まった。",
      "blanks": [ { "no": 1, "answer": "1980", "kind": "年号" } ] },
    { "id": "sa-1-010", "unitId": "sa-1", "type": "mc", "order": 10,
      "stem": "問題文", "choices": ["A", "B", "C", "D"], "answer": [1] }
  ]
}
```

- `type` は `cloze` / `mc` / `multi` / `tf` / `order` のどれか。
- 問題の共通フィールド：`explanation`・`memo`（覚え方）・`page`・`tags`・`important`（頻出）・`retired`（取り下げ）・`refs`（番外編の出典URL）。
- 配列で貼り付ければ、複数のパックを一度に取り込めます。

## 社外秘データの扱い

- 問題パック（JSON）は **リポジトリに入れない** でください。`.gitignore` で `packs/` と `*.pack.json` を除外しています。
- リポジトリに入れてよいのは、アプリ本体と `sample-pack.json`（架空の内容）だけです。
- アプリは問題データを外部に送信しません。通信は GitHub Pages からアプリ本体を読み込むときだけです。

## アップデート

- **問題の追加・訂正**：新しいパックを取り込むだけです（上の手順）。
- **アプリ本体の更新**：GitHub に push すると、次に開いたときに「新しいバージョンがあります［更新］」が出ます。
  更新するときは `sw.js` の `VERSION`（キャッシュ名）も上げてください。

## 開発時の確認

1. `sample-pack.json` を取り込んで、単元一覧に2つ以上の単元が出ることを確認する。
2. 機内モードでも起動して問題が解けることを確認する。
3. 画面幅360pxで横スクロールが出ないことを確認する。
